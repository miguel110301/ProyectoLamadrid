CAPÍTULO 1Cómo está hecho el sistema

Una aplicación local de una sola PC: un servidor que corre en la propia computadora y una pantalla que se abre en Microsoft Edge. No usa internet.

PiezaQué es
ControlMaestro.exeEl sistema: arranca el servidor (sin consola) y abre la pantalla de registro en Edge a pantalla completa. Si ya está corriendo, solo vuelve a abrir la pantalla.
ServidorPython 3.15 + FastAPI, empaquetado con PyInstaller (no hay que instalar Python). Escucha solo en 127.0.0.1:8765: nada fuera de la PC puede conectarse.
Base de datosSQLite en un solo archivo: C:\ControlMaestro\data\tvuaq.db (modo WAL, escritura sincronizada para resistir apagones).
LectorDigitalPersona U.are.U 4500 con el driver WBF, a través de Windows Biometric Framework (WinBio), con una base privada de huellas solo para este sistema.
PantallasHTML, CSS y JavaScript sin dependencias externas: pantalla de registro (/) y administración (/admin.html).
Reportes PDFLos genera el servidor con ReportLab en hoja membretada (provisional hasta tener la oficial).

Dónde vive cada cosa

C:\ControlMaestro\
    ControlMaestro.exe            sistema (pantalla + servidor)
    ControlMaestroConsola.exe     herramientas de instalación y mantenimiento
    _internal\                    librerías (no tocar)
    data\                         TODA la información (se crea sola)
        tvuaq.db                  base de datos
        winbio_config.json        configuración del lector
        registro\servidor.log     bitácora técnica (rota a 1 MB, 5 archivos)
        edge-pantalla\            perfil de Edge de la pantalla
    backups\                      respaldos locales
No borrar ni mover

data\tvuaq.db (toda la información) ni data\winbio_config.json (configuración del lector).

CAPÍTULO 2Requisitos

EquipoWindows 10 de 64 bits (PCMaster_TvUAQ: i7-4790, 12 GB de RAM, disco mecánico).
LectorDigitalPersona U.are.U 4500 conectado por USB.
NavegadorMicrosoft Edge (incluido en Windows 10).
PermisosUna cuenta de Windows con permisos de administrador para instalar el driver y configurar el lector.
HoraZona horaria (UTC-06:00) Guadalajara, Ciudad de México, Monterrey y la hora correcta: las asistencias se calculan con la hora de la PC.
InternetNo hace falta.
Antes de instalar

Si alguna vez se instaló el SDK de HID o el driver «Non-WBF» / legacy del lector, desinstálalos (Panel de control → Programas) y reinicia. El sistema usa el driver WBF.

CAPÍTULO 4Instalación paso a paso

Tiempo aproximado: 45 minutos. Con una cuenta de Windows con permisos de administrador.

  1. Copiar el sistema. Copia la carpeta del kit completa a C:\ControlMaestro\. Si viene en un ZIP, descomprímelo antes de abrir nada. Debe quedar C:\ControlMaestro\ControlMaestro.exe, sin carpeta doble (C:\ControlMaestro\ControlMaestro\). No la pongas en Archivos de programa: ahí Windows no deja guardar la base de datos.
  2. Driver del lector. Doble clic en 1_Instalar_driver_del_lector.bat, acepta todo y reinicia la computadora. Comprueba en Administrador de dispositivos → Dispositivos biométricos que el lector aparezca sin advertencias.
  3. Configurar el lector. Doble clic en 2_Configurar_lector.bat y acepta el permiso de administrador. Debe decir «Base privada creada». Después desconecta el lector y vuelve a conectarlo. Así se crea una base de huellas solo para este sistema, separada de Windows Hello; nunca se guardan imágenes.
  4. Revisar el lector. Doble clic en 3_Revisar_lector.bat: debe aparecer el lector y ningún «Error».
  5. Administradores. 4_Crear_administrador.bat para el administrador del Control Maestro (contraseña de al menos 8 caracteres; no hay usuario por defecto) y 5_Crear_superusuario.bat para la cuenta de respaldo del equipo.
  6. Inicio automático. Doble clic en 6_Inicio_automatico.bat. Desde ahora, al iniciar sesión se abre sola la pantalla en Edge a pantalla completa. Ábrelo ahora con el acceso directo Control Maestro del Escritorio.
  7. Registrar al personal. En la pantalla, Administración → entra con el usuario del paso 5. Registra la huella de cada administrador (Administradores → Huella) y da de alta a cada operador con su horario y su huella (ver el manual de usuario).
Recomendado para los apagones

Inicio de sesión automático en Windows (netplwiz → desmarcar «Los usuarios deben escribir su nombre…») y, en la BIOS, Restore on AC Power Loss = Power On. Así la PC enciende sola al volver la luz y el sistema se abre solo.

Situaciones especiales al configurar el lector

«Huella duplicada» al registrarEse dedo ya estaba en la base del lector (por ejemplo, de pruebas anteriores). Para empezar limpio: consola como administrador en C:\ControlMaestro, ControlMaestroConsola.exe lector quitar y otra vez 2_Configurar_lector.bat.
«Acceso denegado»En regedit: HKLM\SYSTEM\CurrentControlSet\Enum\<ruta del lector>\Device Parameters\WinBio → clic derecho → Permisos → Control total para Administradores, y repetir el paso 3.
«Es de otra instalación»La carpeta vino de otra PC. Vuelve a correr 2_Configurar_lector.bat: crea una base nueva.

CAPÍTULO 7Respaldos y restauración

Cada copia se hace con la API de respaldo de SQLite (sin detener el sistema) y se verifica antes de darla por buena.

AutomáticoCada madrugada, y al encender si pasó más de un día.
ManualAdministración → Respaldos → Respaldar ahora o Respaldar_ahora.bat.
DóndeC:\ControlMaestro\backups\ y, si está configurada, la memoria USB. Archivos tvuaq-AAAAMMDD-HHMMSS.db.
Cuántos7 diarios y 4 semanales (unas 4 semanas), a propósito: los datos de una persona dada de baja no deben quedarse guardados por meses.

Configurar la memoria USB (una vez)

  1. Conecta la USB y anota su letra (por ejemplo E:).
  2. En una consola: setx TVUAQ_RESPALDO_USB E:\TvUAQ
  3. Cierra sesión y vuelve a entrar. Desde ahora cada respaldo también va a la USB; si no está conectada, solo se avisa en Respaldos.
Protección

La USB tiene datos personales: protégela con BitLocker To Go y define quién la resguarda.

Restaurar un respaldo

  1. Doble clic en Restaurar_respaldo.bat: cierra el sistema y lista los respaldos disponibles.
  2. Copia la ruta completa del respaldo que quieres y pégala; Enter vacío cancela.
  3. La base anterior queda guardada aparte. Abre de nuevo con el acceso directo Control Maestro.

CAPÍTULO 8Actualizar a una versión nueva

El sistema solo guarda información en data\ y backups\. Actualizar es cambiar todo lo demás sin tocar esas dos carpetas.

  1. Respaldo: Respaldar ahora; debe decir «Verificado».
  2. Detener: botón Salir y luego Detener_Control_Maestro.bat.
  3. Copia de la versión actual: copia C:\ControlMaestro completa a C:\ControlMaestro_anterior_AAAAMMDD.
  4. En C:\ControlMaestro, borra los dos .exe, _internal\, los .bat, driver_lector_WBF\ y la guía. No toques data\ ni backups\.
  5. Copia todo lo del kit nuevo. Si el kit trae una carpeta data\, no la copies.
  6. Abre con el acceso directo. Si la versión nueva cambia la base, la actualiza sola.
  7. Prueba: una entrada con huella, entrar a Administración y revisar que servidor.log no tenga errores nuevos.
Si algo falla

Detener_Control_Maestro.bat, borra C:\ControlMaestro y renombra la copia anterior a C:\ControlMaestro. Se pierde lo registrado desde la actualización, y la versión anterior no abre una base ya actualizada: por eso la prueba va enseguida. Cuando la nueva lleve unos días bien, borra la copia anterior (tiene datos personales).

CAPÍTULO 9Solución de problemas

SíntomaQué hacer
Pantalla: «El lector de huellas no responde»Desconecta el lector, espera 5 s y conéctalo. Si sigue: 3_Revisar_lector.bat y reinicia la PC. Si se repite, el log dirá «falla del lector».
Pantalla: «Sin conexión con el sistema»El servidor no está corriendo: abre el acceso directo Control Maestro. Si se repite, revisa servidor.log.
«Huella no reconocida»Dedo limpio, plano y centrado; el mismo con que se registró. Si sigue, borrar sus huellas y registrarlas de nuevo.
«Esa huella ya está registrada en el lector»Usa otro dedo, o empieza con una base limpia (capítulo 4).
«El lector está ocupado» por mucho tiempoSe quedó abierto un registro de huella en la administración: pulsa Cancelar ahí (el registro se cancela solo a los 90 s).
La pantalla no abreComprueba que Edge esté instalado. Ábrela a mano: http://127.0.0.1:8765/.
Las horas salen corridasRevisa la zona horaria y la hora de Windows (capítulo 2).
Aviso «USB no conectada» en RespaldosConecta la USB con la misma letra configurada y pulsa Respaldar ahora.

CAPÍTULO 11Seguridad y datos personales

RedEl servidor solo atiende desde la propia PC (127.0.0.1) y rechaza peticiones de otros orígenes. No habilites Escritorio remoto ni carpetas compartidas.
ContraseñasSe guardan con scrypt, nunca en claro. Mínimo 8 caracteres; se rechazan las triviales.
SesionesCaducan a los 30 minutos sin uso; bloqueo de 5 minutos tras 5 intentos fallidos.
RolesOperador, administrador y superusuario. Los permisos se revisan en el servidor, no solo en la pantalla.
HuellasLas plantillas quedan en la base privada de WinBio de la PC; en la base del sistema solo su identificador. No se guardan imágenes y no salen de la PC.
Aviso de privacidadLa persona debe aceptarlo antes de registrar su huella. El texto actual es provisional: el oficial lo debe dar la UAQ.
BajasA los 30 días se borran datos, huella e historial de la persona (revisión automática cada hora); solo queda una línea en la bitácora sin datos personales.
BitácoraInicios de sesión, cambios de horario, justificaciones, ediciones, bajas, respaldos y PDF generados quedan registrados.
Windows 10Terminó su soporte gratuito en octubre de 2025: mantener la PC sin servicios expuestos y con el antivirus de Windows activo.

CAPÍTULO 12Para el equipo de desarrollo

Estructura del código

control_maestro/
    app/          servidor FastAPI: api/ (rutas), db/ (esquema), reglas/ (reglas de turnos),
                  biometria/ (adaptador del lector), reportes/ (reportes y PDF)
    lector/       lógica del lector WinBio
    web/          pantallas HTML/CSS/JS sin frameworks, con fuentes locales
    tests/        pruebas del sistema y del lector
    scripts/      demostración, arranque y construcción del kit en Windows
    empaquetado/  receta de PyInstaller (--onedir)
    docs/         instalación, pendientes y documentación del lector
    externos/     driver WBF e instalador de Python 3.15.1 (fuera de git)
  • Las reglas de negocio existen solo en app/reglas/; las pantallas y los PDF usan los mismos datos del servidor.
  • Desarrollo con lector simulado: ./scripts/demo.sh reiniciar (usuario demo). Pruebas: python -m pytest.

Construir el kit

  1. En una VM con Windows 10 x64, instala Python 3.15.1 de 64 bits (externos\python-3.15.1-amd64.exe, marcando Add python.exe to PATH).
  2. Desde la carpeta del proyecto: powershell -ExecutionPolicy Bypass -File scripts\windows\construir.ps1 (instala dependencias, corre las pruebas, construye y arma dist\ControlMaestro\).
  3. Sin internet en la VM: antes, en otra PC, scripts\windows\descargar_paquetes.ps1 deja los paquetes en vendor\wheels\.
  4. Antes de copiar el kit, revisa que dist\ControlMaestro\ no tenga data\ (se crea si se abrió el .exe para probarlo).
Cuidado

PyInstaller borra dist\ControlMaestro\ completo al reconstruir, incluida su data\.

Dependencias fijas

Versiones exactas en requirements.txt y constraints.txt (FastAPI 0.156.4, Starlette 1.9.0, Pydantic 2.14.1, Uvicorn 0.54.0, ReportLab 5.1.0, Pillow 13.0.0). Solo se cambian a propósito y con las pruebas en verde.
